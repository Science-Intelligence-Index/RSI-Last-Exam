# SII public website

Scientific Intelligence Index 主站，包含中英文首页、研究方法、科学领域、材料与多组学页面、任务与资源目录、教学演示、使用指南、合作草稿、动态和项目说明。

白底、低饱和橙蓝配色，领域使用独立主题色。科学图形为 SVG，研究愿景示意支持逐步选择、一次播放、暂停和减少动态效果模式。

## Run locally

Node.js 22+，无第三方构建依赖，无需安装 npm 包。

```sh
npm run dev
```

打开 `http://127.0.0.1:4173/zh/`，英文入口为 `/en/`。开发脚本会在源文件变化后重建，刷新浏览器即可查看。可用 `PORT` 环境变量指定端口。

```sh
npm run build
npm run check
```

`dist/` 为静态站点产物，部署时需支持目录 `index.html` 和真正的 404 响应。根路径指向英文首页，语言切换保留对应页面。尚未配置正式域名和部署。

## Current boundaries

- 公开内容仅描述 SII Bench 的目标、概念与领域方向，不包含精确的核心数据设计流程；开发与发布须遵循 [披露守则](AGENTS.md)。
- 教学记录来自第三方公开资源；浏览器演示和下载 JSON 仅用于说明这些记录，不代表 SII Bench 的核心数据设计或评测协议。内部方案及附件不随主站发布。
- 材料示例为一个公开教学族、两个候选与两条计算性质观测。它不代表学习增益实验或隐藏评测。
- 目录支持搜索与类型筛选；演示在两次选择后显示公开参考，选择不发送到后端。
- 合作意向仅在浏览器中生成，可下载或复制。没有在线收件、账户或 Agent 后端。
- 合作收件地址与闭源工作台入口尚未指定，界面如实显示待开放状态。
- 领域可在主站直接承载，也可经配置链接到独立专题。

领域卡片默认链接主站详情；需要独立专题时，在 `src/content.mjs` 对应领域条目增加 `entryUrl` 即可。科学问题、状态、主题色和合作需求在同一条记录维护。

## Verification

首版已检查30个静态HTML文件（其中28个中英文内容页面）和865个本地引用。浏览器检查覆盖390像素下的全部中英文页面，以及360、768、1024和1440像素下的代表页面，修复了英文领域卡片溢出。

构建会清理并重新生成本仓库的 `dist/`，检查脚本核对完整产物清单，防止旧附件残留。文件清单检查不能代替发布前的内容审阅；需同时检查源码、可下载文件和中英文生成页面。

已实际操作目录的空结果与类型筛选、语言切换、手机导航、双观测选择与重置，以及合作草稿的空白拒绝、缩进保留、文字转义和Markdown下载。页面无后台数据提交，闭源工作台尚未接入。
